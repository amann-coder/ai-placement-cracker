# AI Placement Cracker 🎯

An AI-powered interview preparation tool that generates role & company-specific Q&A, tips, and weak-area improvements.

## 🚀 Features
- Full Prep: 3 Q&A + tips + selection score + weak areas
- Quick Revision: 3 rapid Qs + 3 tips
- Simple frontend with clean card-based UI
- Backend powered by Node.js, Express, Groq SDK, and OpenAI

## 🛠️ Tech Stack
- Node.js + Express
- Groq SDK + OpenAI API
- HTML, CSS, JavaScript (frontend)
- Deployment: Render

## 📂 Setup
1. Clone repo
2. Run `npm install`
3. Add your `GROQ_API_KEY` in `.env`
4. Start server: `npm start`
5. Open `index.html` in browser
